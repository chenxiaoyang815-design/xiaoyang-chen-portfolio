# Xiaoyang Chen / 陈萧仰 — Bilingual Portfolio

一款面向技术招聘方的中英双语个人网页简历，重点展示数据工程、数据分析、软件交付与真实客户协作能力。

## 本版本包含

- 中英文一键切换，并自动匹配中英文简历下载
- 以 COMP9900 Atlassian 客户项目为核心，展示真实 Jira 数据连接、后台用户信息、计算结果、知识产权与数据治理
- 机器学习时间序列预测、MapReduce、NSW 燃油数据与 PostgreSQL 项目
- 中富通实习、三段教育经历、完整技术栈
- UNSW Employment Award 与 EY 合作招聘流程、团队技术问题分析及多维项目提案
- 志愿者与领导力经历、奖项、出版信息、证书和语言能力
- 桌面端、平板与手机端响应式布局
- 可交互的 Jira 合成数据视图、30 / 60 / 90 天发布窗口和计算信号演示
- 青蓝、电紫、品红、薄荷绿与琥珀构成的多色科技视觉系统

## 隐私范围

项目仅包含网页所需的个人证件照、中英文简历与公开联系方式。身份证、护照、移民文件、客户会议原始 PDF 等资料没有被打包或公开。

## 本地预览

1. 在该目录打开终端。
2. 运行 `npm install`。
3. 运行 `npm run dev`。
4. 打开终端显示的本地地址。
